Internal tool — not linked from the public site

This page is for BAA team members only. It does not upload anything — you'll download a ZIP and upload it yourself via the GCS console. Do not run this at the same time as another teammate (see instructions after generation).
Next steps:
  1. Download the ZIP above (if you haven't already).
  2. Extract it — you'll see a certs/ folder and an index/ folder.
  3. Go to console.cloud.google.com and open the bucket.
  4. Upload the extracted certs/ and index/ folders into the bucket, keeping the same folder structure.
  5. When prompted, overwrite any files with the same name — the index files in this ZIP already include the previously-existing records merged in, so overwriting is safe as long as no one else uploaded a change to the same index file after you generated this ZIP.
